# Contributing to Cobra IDE

Thank you for helping improve Cobra IDE. Everyone is welcome to contribute.

## How to Help

### Report a Bug

If you find a bug:

1. Check existing issues to see if it was already reported.
2. Open a new issue with a clear title.
3. List the steps to reproduce the problem.
4. Tell us what you expected to happen and what actually happened.
5. Add screenshots or error logs if you have them.

### Suggest a Feature

Have an idea for a new feature?

1. Check existing issues first.
2. Open a new issue describing what the feature does and why it helps.

### Send a Pull Request

1. Fork this repository.
2. Create a new branch for your changes (`git checkout -b my-feature`).
3. Make your changes and test them.
4. Keep your code style clean and consistent.
5. Open a pull request with a short summary of what you changed.

## Code Style

- Use 4 spaces for indentation.
- Follow standard C# naming rules (PascalCase for classes and methods).
- Keep functions short and easy to read.
- Use the dark orange accent color (`#ff8c00`) for primary UI actions.

## UI Style

- Use simple, short text on buttons, tooltips, and labels.
- Set text size to `12` for standard UI text.
- Use MahApps icon packs with a standard size of `14x14`.
- Keep spacing and margins consistent.
